# 🤖 Smart Rule-Based Chatbot

A simple and interactive Rule-Based Chatbot built using Python.  
This chatbot responds to user inputs using predefined rules and conditions with the help of `if-elif-else` statements.

It is a beginner-friendly project designed to understand the basics of:
- Chatbot development
- Conversation flow
- User input handling
- Basic Natural Language Processing concepts

---

## ✨ Features

✔️ Interactive chatbot conversation  
✔️ Greeting responses  
✔️ Time and date functionality  
✔️ Random joke generator  
✔️ Help command support  
✔️ Simple math response  
✔️ User-friendly interface  
✔️ Beginner-friendly Python project  

---

## 🛠️ Technologies Used

- Python
- Datetime Module
- Random Module
